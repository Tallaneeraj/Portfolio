# 📊 RFM Analysis using Python

This project demonstrates **RFM (Recency, Frequency, Monetary) analysis** to segment customers based on their purchasing behavior. RFM is a proven marketing technique used for customer segmentation and targeted strategies in customer relationship management (CRM).

---

## 📁 Project Overview

- **Notebook Name**: `RFM_Analysis.ipynb`  
- **Purpose**: Analyze customer data using RFM methodology to identify high-value customers and segment them into actionable categories.  
- **Dataset**: A sample e-commerce transactions dataset.  
- **Tech Stack**: Python, Pandas, Seaborn, Matplotlib

---

## 📌 Key Concepts

- **Recency**: How recently a customer made a purchase.
- **Frequency**: How often they purchase.
- **Monetary**: How much money they've spent.

---

## 🔧 Steps Involved

1. **Data Cleaning**: Handling missing values, removing duplicates, and filtering out invalid transactions.
2. **Feature Engineering**: Creating RFM metrics from the transactional data.
3. **Scoring**: Assigning scores to each RFM metric.
4. **Segmentation**: Combining RFM scores to categorize customers (e.g., "Champions", "Loyal Customers", "At Risk", etc.).
5. **Visualization**: Displaying customer segments and distributions using plots.

---

## 📈 Visualizations

The notebook includes:
- Histograms for R, F, and M distributions
- Heatmaps of RFM segments
